# Итоговый проект — План задач по программированию

- **Автор:** <ваше имя>
- **Вариант:** 9 (amount — количество баллов, completed — задача решена)
- **Python:** 3.10+
- **Запуск:** `python main.py`
- **Тесты:** `python -m pytest -v`

## Назначение
Консольная программа для учёта задач по программированию: добавление, поиск,
изменение статуса, удаление, статистика, сохранение в JSON.

## Формат данных (`data.json`)
Список объектов: `id` (положительное целое, уникальное), `title`, `category`
(непустые строки), `amount` (целое ≥ 0, баллы), `completed` (строго bool).
Корень — список. Дополнительные ключи сохраняются без обработки.

## Структура
- `logic.py` — валидация, добавление, поиск, статус, удаление, статистика.
- `storage.py` — чтение/запись JSON (без консоли).
- `main.py` — меню и ввод.
- `test_logic.py`, `test_storage.py` — автотесты.

## Приёмка (записано вручную)
| Сценарий | Результат |
|---|---|
| Файла нет | `[]`, меню работает |
| `data.json` = `[]` | статистика: все нули |
| Добавлены 4 и 2, вторая завершена | всего 2, выполнено 1, не выполнено 1, сумма 6 |
| Название `  Python  ` | сохранено `Python` |
| Поиск `PY` при `Python` | найдено |
| Пустое имя, `amount=-1`, `amount=abc` | повторный ввод, запись не появляется |
| Статус неизвестного ID | сообщение, данные не изменены |
| Удаление отменено | запись сохранена |
| Удалён ID 1 из [1, 2] | остаётся ID 2; новая получит ID 3 |
| Сохранение и перезапуск | всё восстановлено |
| Повреждённый JSON / повторный ID | запуск прекращён, файл не изменён |
| Ошибка сохранения | нет сообщения об успехе, работа продолжается |

## Путь одной записи
Ввод «Новая задача / учёба / 3» → `add_record` → список в памяти →
`save_records` → JSON в `data.json` → при старте `load_records` +
`validate_records` → снова в списке.
